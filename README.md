# وكيل الأفكار الاستراتيجية

سبعة وكلاء متسلسلين يحوّلون موضوعاً واحداً إلى تقرير استراتيجي موثّق بمصادر،
ينتهي بحلول عملية ينفّذها فرد واحد.

```
جمع المصادر ← بحث موثّق ← أفكار مضادة ← تناقضات ← سيناريوهات
                                    ← نقد قاسٍ ← دمج استراتيجي ← حلول فردية
```

## التشغيل

```bash
.venv/Scripts/python.exe app.py
```

أو من الملف التنفيذي: `dist/IdeaAgent/IdeaAgent.exe` — يفتح المتصفح تلقائياً
على `http://127.0.0.1:8730`.

للطرفية بدل المتصفح: `python main.py`

### لماذا واجهة ويب؟

الطرفية شبكة خانات أحادية العرض بلا bidi: العربية فيها إما منفصلة الحروف
(`ن ش ت غ ل`) أو مبعثرة الترتيب. المتصفح يتقن التشكيل والاتجاه ويسمح بتصميم
فعلي. و`uvicorn`/`starlette` موجودان أصلاً مع crewai — صفر تبعيات جديدة.

### سرعة الإقلاع

استيراد crewai يكلّف ~11 ثانية (وأضعافها داخل EXE). أُجّل داخل الدوال بدل
رأس الملف، فصار الإقلاع **0.6 ثانية للنسخة العادية و3 ثوانٍ للـEXE** بدل ~60.
crewai لا يُستورد إطلاقاً حتى تبدأ تشغيلة فعلية.

## الإعداد

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt   # لينكس: .venv/bin/pip
cp .env.example .env
```

ثم املأ المفاتيح في `.env`:

| المتغير | إلزامي | من أين |
|---|---|---|
| `OPENROUTER_API_KEY` | نعم | https://openrouter.ai/settings/keys |
| `SERPER_API_KEY` | لا (لكن بدونه لا بحث حقيقي) | https://serper.dev — 2500 طلب مجاناً |
| `MODEL` | لا | افتراضياً نموذج مجاني |
| `RUN_TIMEOUT` | لا | سقف التشغيلة بالثواني، افتراضياً 1500 (25 دقيقة) |
| `MAKE_PDF` | لا | `0` افتراضياً — التقرير يُعرض في الصفحة، وزرّ «تصدير PDF» يولّده عند الطلب |
| `HIDE_SOURCES` | لا | `1` افتراضياً — يحذف المصادر من نص التقرير |
| `AUTO_UPDATE_HOURS` | لا | `6` افتراضياً — دورة رادار الفرص · `0` يعطّلها |

> `profile.json` في المستودع هو ملف مالكه التعريفي، لا قالب فارغ. إن
> استنسخت المشروع فاستبدله بملفك: كل حكم على «الملاءمة» — وزنها 0.30،
> الأثقل في تسجيل الفرص — يُبنى عليه.

### المصادر عند الطلب

التقرير المعروض **بلا روابط** — نص نظيف. لكن الوكلاء يواصلون إنتاج المصادر
لأن الـ`guardrail` يفرضها، وهي ما يمنع اختراع الأرقام. تُخزَّن في
`knowledge.db` قبل الحذف، وتُسترجع وقت الحاجة:

```bash
python memory.py sources              # كل المصادر مرتّبة بعدد الحقائق
python memory.py sources تحلية        # مصادر موضوع بعينه
python memory.py search نترات         # حقيقة بعينها مع مصدرها
```

لإبقاء المصادر داخل التقرير: `HIDE_SOURCES=0` في `.env`.

### مخرجات PDF

كل تشغيلة تنتج `.md` و`.pdf` معاً. التحويل عبر Edge بوضع headless:

```bash
python pdf.py output/تقرير.md
```

**لماذا Edge لا مكتبة PDF؟** العربية تحتاج تشكيل حروف واتجاهاً ثنائياً.
`reportlab` و`fpdf` تطبع الحروف منفصلة ومقلوبة ما لم تُضف `arabic-reshaper`
و`python-bidi`، ثم تنكسر الجداول. محرّك المتصفح يتقن ذلك، وEdge مثبّت مع
ويندوز 11 — فصفر تبعيات جديدة.

الروابط تُطبع بعناوينها الكاملة بجانب نصّها، فتبقى المصادر قابلة للتحقق على الورق.

### السقف الزمني

`max_retries` و`timeout` يحميان من فشل المكالمة الواحدة، **لا من التعليق
الكلي**. رُصدت تشغيلة عالقة 57 دقيقة على مزوّد مجاني متعثّر باستهلاك 11
ثانية معالج فقط — انتظار شبكة صامت بلا نهاية.

عند تجاوز `RUN_TIMEOUT` تتوقف التشغيلة ويُحفظ **تقرير جزئي** يذكر في ترويسته
عدد المراحل المكتملة وأسماء الناقصة. لا تُفقد المراحل المنجزة.

### التشغيلات المهجورة

إغلاق التبويب أثناء التشغيل لا يُقفل التطبيق. `/api/status` يعرض التشغيلة
الجارية (موضوعها، مرحلتها، زمنها) وأي تبويب جديد يراها مع زر إلغاء.

الواجهة تستهلك البث بـ`fetch` لا `EventSource` عمداً: الأخير **يعيد الاتصال
تلقائياً**، فتبويب متروك كان يعيد تشغيل موضوع قديم عند كل إعادة تشغيل للخادم
ويحرق حصة النموذج بلا علم صاحبه. وصفحة الواجهة تُرسَل بـ`no-store` حتى لا
يبقى تبويب يحمل منطقاً قديماً.

الوكلاء يُبنون من جديد لكل تشغيلة بلا تخزين عالمي — البناء 1.5 ثانية مقابل
8 للاستيراد، والمشاركة كانت تسبّب `RuntimeError: Executor is already running`.

### النماذج المحلية (Ollama)

يدعم `ollama/<نموذج>` — بلا مفتاح، بلا إنترنت، بلا تكلفة. المبدّل في الواجهة
يعرض ما هو منزّل عندك ويسمح بالتبديل لكل تشغيلة.

```bash
MODEL=ollama/qwen2.5:3b python app.py
```

**قياسات فعلية على Ryzen 5 7520U / 14GB / رسوميات مدمجة 2GB:**

| النموذج | السرعة | تشغيلة كاملة |
|---|---|---|
| `openrouter/minimax-m3:free` | — | **4 د 16 ث** ✅ |
| `qwen2.5:3b` | 5.6 رمز/ث | رسب في حاجز المصادر بعد 17 د ❌ |
| `qwen2.5:7b` | 2.7 رمز/ث | ~90 د (غير مُختبَر) |
| `qwen3:8b` | 2.2 رمز/ث | ~110 د (غير مُختبَر) |

**الخلاصة الصادقة:** على هذا العتاد، المحلي ليس أسرع بل أبطأ 10-20 ضعفاً.
و`qwen2.5:3b` أنتج **صفر روابط مصادر** ثلاث مرات رغم حقن نتائج بحث كاملة —
فرفضه الحاجز. المكسب من المحلي هو الاستقلال عن الرصيد والإنترنت، لا السرعة
ولا الجودة. لعمل جدّي على هذا الجهاز، ابقَ على السحابي.

يحتاج `ollama serve` يعمل؛ الواجهة تفحصه وتخبرك إن كان متوقفاً.

### جودة المصادر

البحث العام يعيد ما يتصدّر جوجل: مواقع مورّدين ومنصات تواصل. قياس فعلي
على تشغيلة كاملة أعطى **متوسط وزن 0.34 وصفر مصدر محكّم من 15**.

حصر النطاق بـ `site:` عالج العَرَض لا السبب — الدوريات لا تتصدّر البحث
العام أصلاً. الحل أن نسأل قواعد البيانات العلمية مباشرة: OpenAlex
وCrossref مفتوحتان بلا مفتاح ولا حصّة، وكل نتيجة منهما تحمل DOI.

قيد مقيس: الاستعلام العربي على OpenAlex يعيد **صفر** نتيجة — الفهرسة
إنجليزية. فيُترجَم الموضوع بنداء واحد رخيص مخزَّن قبل البحث.

| | قبل | بعد |
|---|---|---|
| متوسط وزن المصدر | 0.34 | **0.69** |
| دوريات محكّمة | 0 | **13** |
| منصات تواصل | 4 | **0** |

### الخدمات

ثماني عشرة خدمة خلف `python services.py <id>` أو زرّ «الخدمات» في
الواجهة. السريعة تقرأ من قاعدة المعرفة وترجع فوراً؛ البطيئة تستدعي
النموذج وتأخذ دقائق، وتشارك قفل التشغيل الذي يحمي التقارير من التداخل.

```bash
python services.py            # الفهرس
python services.py trust      # توزيع المصادر على طبقات الثقة
python services.py warroom "هل نبيع اشتراك مراقبة بدل بيع المحطات؟"
```

### التحديث التلقائي

خيط داخل الخادم لا مهمّة في مجدول ويندوز: المهمّة الخارجية تحتاج
صلاحيات وتنكسر عند نقل المجلد، والخيط يعيش مع البرنامج ويموت معه.

الحالة تُحفظ في `schedule.json`، فإغلاق البرنامج ليلاً وفتحه صباحاً لا
يعيد جولة تمّت قبل ساعة ولا يؤجّل جولة فاتت منذ يومين.

```bash
AUTO_UPDATE_HOURS=3 python app.py    # الافتراضي 6 · صفر يعطّله
python scheduler.py                  # الحالة
python scheduler.py --run            # جولة الآن
```

### Agent Skills

المعيار المفتوح من [agentskills.io](https://agentskills.io). كل مهارة مجلد فيه
`SKILL.md` برأس YAML (`name`, `description`, `keywords`) ونصّ حرّ بعده.

```bash
python skills.py list                  # المهارات المتاحة
python skills.py "أغشية التناضح"        # أيها يطابق موضوعاً
```

تُحقن في مهام **البحث والنقد والحلول الفردية** فقط — لا في مهام التوليد
الإبداعي، فتقييدها بخبرة المجال يخنق تنوّعها. وتُحمَّل فقط عند تجاوز عتبة
تطابق 0.2 حتى لا يتضخّم السياق بلا داعٍ.

المهارة الجاهزة `skills/reverse-osmosis/` قالب: جداول تشخيص الأعطال، ترتيب
الغسيل الكيميائي، وأرقام مرجعية للحكم على معقولية ما يرد في البحث.

### وكيل التصفح

`Serper` يعيد عنواناً ومقتطفاً — يكفي لأغلب الادعاءات. وكيل التصفح لِما لا
يكفي فيه ذلك: رقم داخل جدول، أو خلف نموذج، أو في تقرير مرتبط.

**معطّل افتراضياً بقصد:** زيارة صفحة 20-60 ثانية مقابل ثانية لبحث Serper —
تشغيله دائماً ينسف مكسب السرعة.

### المحكّم المستقل (Mastra)

Mastra إطار TypeScript بلا SDK لبايثون، فيعمل كخادم Node جانبي على 8740.
ولئلا يكرّر ما يفعله CrewAI، دوره واحد: **حكم من خارج الطاقم** على التقرير
— الطاقم لا يقيّم نفسه بحياد.

```bash
cd mastra && npm install && node server.mjs
JUDGE=1 python judge.py output/تقرير.md
```

يُذيّل التقرير بجدول من 50 درجة على خمسة محاور، مع تشخيص الأضعف وخطوات
التحسين. يُحكَّم على النسخة **الموثّقة** لا المجرّدة من المصادر — وإلا
عاقبنا التقرير على مصادر نحن حذفناها.

## كاشف الفرص

يقلب السؤال: بدل «أخبرني عن X»، النظام يراقب مجالك ويخبرك.

```
مصادر → جمع → تصنيف → مطابقة ملفك → تسجيل → فريق أحمر → تنبيه
```

```bash
python opportunity_run.py           # دورة كشف كاملة
python opportunity_run.py list      # الفرص المرصودة سابقاً
```

**أولاً عرّف شركتك في `profile.json`** — بدونه لا معنى لكلمة «مناسبة».
الحقول: القدرات، المنتجات، القطاعات المستهدفة، المواقع، سقف الميزانية،
حجم الفريق، المشاريع السابقة، و**`avoid`** (ما تستبعده صراحة).

### التسجيل

سبعة عوامل مرجّحة، **تُحسب في الكود لا في النموذج**:

| العامل | الوزن | المصدر |
|---|---|---|
| الملاءمة `fit` | 30% | النموذج |
| السوق · التوقيت · الربحية | 15% لكلٍّ | النموذج |
| المنافسة · المخاطر | 10% لكلٍّ | النموذج، **معكوسة** (الأعلى أسوأ) |
| جودة الأدلة | 5% | الكود — عدد المصادر |

ثم عقوبات يعرفها الكود وحده: مسّ بند في `avoid` يضرب في 0.6، وغياب
السند كلياً يضرب في 0.5.

**لماذا لا يسجّل النموذج؟** لأنه يعطي كل شيء 90. رُصد هذا فعلاً في وكلاء
المشروع: متوسطات 96-100 قبل إعادة التسجيل.

### النطاقات

| الدرجة | القرار |
|---|---|
| 85-100 | **HIGH** — أولوية قصوى |
| 70-84 | INVESTIGATE — حقّق فوراً |
| 50-69 | WATCH — راقب |
| 0-49 | IGNORE |

الفريق الأحمر يهاجم ما تجاوز 70 فقط، **ويخصم فعلياً** حتى 25% — نقد بلا
أثر على الدرجة زينة لا حُكم.

### تشغيلة حقيقية

48 خبراً → 12 فرصة مصنّفة. أعلاها 66 (WATCH): مناقصات RO لمستشفى ومختبر،
توسعة نماء ظفار، تأهيل موردي OSWS. والفريق الأحمر أسقط واحدة بحجة:
«فريق من 3 أفراد وميزانية 50 ألف لا ينافس موزعين معتمدين بعقود حصرية».

**لم تظهر فرص HIGH** — و`profile.json` لا يزال قالباً (`"اسم شركتك"`).
املأه ببياناتك الحقيقية وستتغيّر درجات الملاءمة جوهرياً.

## الذاكرة المعرفية

مستوحاة من مخطط [Semantica](https://github.com/semantica-agi/semantica)، لكن على
SQLite فقط — بلا Neo4j ولا خوادم.

```bash
python memory.py                          # إحصاءات
python memory.py search نترات             # بحث فوري
python memory.py ingest output/x.md موضوع  # ابتلاع تقرير
```

كل تشغيلة تُضاف للقاعدة، فتتراكم المعرفة عبر الوقت. البحث عبر FTS5 يستغرق
أقل من مللي ثانية ولا يحتاج شبكة.

### ما أُخذ من Semantica

| المفهوم | التنفيذ هنا |
|---|---|
| المصدر على مستوى الحقيقة (PROV-O) | كل صف في `facts` يحمل `source_url` و`confidence` |
| الزمن الثنائي | `valid_from`/`valid_until` مقابل `recorded_at` |
| دمج الكيانات | تطبيع عربي + عتبة تشابه 0.85 + `merge_log` |
| حواف مُسمّاة | جدول `edges` مع `rel` و`weight` |
| القرارات ككائنات | `decisions` + `causal` بعلاقات CAUSED/INFLUENCED/PRECEDENT_FOR |

لم يُؤخذ عمداً: Rete/Datalog/SPARQL و Allen interval algebra — ثقيلة بلا عائد هنا.
